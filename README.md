## 关于我们

成都哟罗机器人有限公司（YoluoRobotics）成立于 2021 年，专注**无人机 AI 与机器人教育**两大方向：

- 🛸 **无人机智能体开发**：基于 ROS、LangChain、YOLO、VLM 的多智能体 UAV 控制系统，已应用于巡检、应急、反无人机对抗等场景。2025 年获**全国青少年智能无人系统应用大赛地面反无人机群挑战赛二等奖**。
- 🏆 **机器人教育与竞赛培训**：为大中小学提供单片机 → STM32 → ESP32 课程体系、RoboMaster/无人机竞赛全流程指导。
- 💡 **UAV Agent 技术咨询**：为大客户定制语言条件化机器人操控方案。
